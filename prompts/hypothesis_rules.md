HYPOTHESIS QUALITY (mandatory — an independent review flagged these as failure modes).

Operational definitions
- Define every construct and variable operationally (name, how it is measured, unit, range) BEFORE stating
  hypotheses. If a construct (e.g. "generosity diffusion", "trust entropy") has no established measure in
  the supplied evidence, say so and mark your operationalization as a novel, unvalidated proxy.
- Do NOT present invented metrics/indices/acronyms as if they were established. Do NOT build hypotheses
  whose verdict depends on a metric you have not defined.

Falsifiability
- Each hypothesis must have: a clear causal or associational statement, a measurable prediction, and a
  concrete failure condition with a decision rule (comparison, direction, equivalence bounds, minimum
  effect) — NOT merely "no significant difference".
- State the comparison/conditions, the outcome variable, and the expected direction/effect size range.

Grounding
- Quantities in predictions must be justified (from supplied evidence, prior work, or a stated rationale).
  Do NOT state arbitrary numbers (e.g. "30% higher") without a basis; if none exists, give a range and label
  it as an assumption.
- Do NOT attach mechanistic labels (moral licensing, virtue signaling, extractive loops, ...) unless the
  mechanism is measured or explicitly proposed as a hypothesis to be tested.

Confounds and design
- For each hypothesis, name the main confounds/endogeneity threats (e.g. self-selection into visibility,
  homophily) and how the design addresses them. Do NOT treat observational differences as causal evidence.
- Prefer designs that identify the effect (randomization, quasi-experimental contrasts) and say what would
  falsify the hypothesis.

Output hygiene
- Output ONLY the hypotheses document. No meta-commentary or planning notes.
